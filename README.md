# prueba: PHP + MySQL CRUD Practice

A small practice app built to learn server-side PHP. It manages a list of universities and their courses, with create, read, update and delete pages backed by a MySQL database.

## What's inside

- `index.php`: lists universities
- `create.php`, `show.php`, `edit.php`, `delete.php`: CRUD pages
- `auth/`: database connection and query helpers (`getuniversities.php`, `getcourses.php`, `adduniversity.php`)
- Styled with Bootstrap 5

## Tech stack

PHP, MySQL (mysqli), Bootstrap 5
